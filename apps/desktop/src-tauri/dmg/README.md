# Gustaf installer artwork

The light warm background keeps Finder's dark icon labels legible. Native Gustaf and Applications icons sit at (180, 228) and (540, 228), with a central arrow; the saved content area is 720 × 440 points. The header uses the owner's current raven mark, copied into this packaging-only asset directory. No Blender artwork is used.

`background.png` is 720 × 440 at 72 dpi; `background@2x.png` is 1440 × 880 at 144 dpi. The raster files are committed, so CI does not require a graphics tool or font installation. The image has no baked-in icon labels: Finder supplies the real filenames.
