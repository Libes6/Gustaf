# Mobile notifications

Background alerts that depended on a hosted connect service are not available in Gustaf. The
Android app does not receive push notifications, live updates, or home-screen agent activity while
it is disconnected from your computer.

While the app is connected over the local network, Tailscale, or the
[Gustaf relay](./remote-access.md#gustaf-relay), open the thread in the app to see that the agent
finished, failed, or is waiting on you.
