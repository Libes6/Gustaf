# MCP servers

Part of the [M Code documentation](../README.md).

Settings, MCP servers: connect [Model Context Protocol](https://modelcontextprotocol.io) servers and the agents of **API providers** (OpenAI, Anthropic, Gemini, OpenRouter, local models) can use their tools. **Claude Code, Codex and Cursor Agent use their own MCP configuration; M Code does not inject servers into them** (the list is not shared with them either).

- **Servers:** local servers over stdio (`command`, `args`, `env`, optional working directory; started from an argument array, never through a shell, with the login-shell `PATH`, so `npx`/`uvx` work) and remote servers over streamable HTTP (`url`, `headers`; JSON and SSE responses; `https://`, or `http://` to localhost). The legacy SSE transport is not supported. Each server is global or bound to one project, and can be disabled. Paste an `mcpServers` JSON block (Claude Desktop, Cursor, VS Code shape) with "Import JSON", or load `~/.cursor/mcp.json`.
- **Secrets:** env values and headers marked "Secret" (ticked automatically for names like `*_TOKEN`, `Authorization`) are stored in the macOS Keychain (`mcp:<server id>:env|header:<name>`), never in the settings database, and are removed with the server.
- **Lifecycle:** a stdio server starts on first use (or "Test connection"), does the `initialize` handshake, and is restarted with backoff if it crashes (at most 5 crashes in a row, then "Error" until started again). It is killed when disabled, edited, removed or when the app quits. Messages are capped (16 MB in, 4 MB out), every call has a timeout (60 s by default, per server), stderr goes to a bounded log shown under "Log". `notifications/tools/list_changed` refreshes the tool list.
- **In the agent:** tools are offered as `mcp__<server>__<tool>` (at most 64 characters, collisions get a numeric suffix) with their JSON Schemas sanitized and size-capped. Main agent only (subagents keep their fixed tool set). Results (text, one PNG image, resource links, embedded text resources) become tool results capped at 50,000 characters; other binary content is replaced by a note.
- **Approvals:** every call asks by default (Full access does not skip it). "Always allow" can be set per tool (also from the approval card) or per server. In read-only mode only tools you marked "Read-only" are offered and callable; hints from the server are shown but not trusted. Calls appear in the action log as `mcp__<server>__<tool>`. Tool output is untrusted data and the system prompt says so.

Logic: `src/agent/mcp/` (`config.ts`, `protocol.ts`, `toolset.ts`: pure; `http.ts`: HTTP client over an injected `fetch`; `runtime.ts`: settings, Keychain and connections), `src-tauri/src/mcp.rs` (stdio runtime), `components/McpServers.tsx` (UI).
