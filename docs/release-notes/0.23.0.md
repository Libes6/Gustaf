## What’s new

- Gustaf’s desktop app now runs on Electron, with installers for macOS (Apple silicon), Windows and Linux (AppImage and .deb). The Android app is attached as an APK.
- Updates come from Gustaf’s GitHub releases and are verified against Gustaf’s own signing key before they install.
- Usage limits can show what you have used or what is left, under Settings → Appearance, on desktop and mobile.
- The folder sidebar with two-line thread rows is on by default.
- Settings → MCP shows roughly how many tokens each server’s tools add, and threads without a browser or devices no longer list those tools.
- Thread and prompt links you copy are `gustaf://` links that open the app. Hosted-app and T3 Connect links are gone.
- Theme animations pause while the window is unfocused or idle, which keeps idle CPU and GPU use near zero.
- Gustaf’s name and icons now show in the menu bar, Dock and About screen.

## Notes

- The installers are not signed with an Apple or Microsoft certificate, so macOS and Windows warn the first time you open them. Updates installed from inside the app do not.
