## What’s new

- Shared skills in `<workspace>/.agents/skills` and `{userdata}/skills` work across every provider from the composer (`/` and `$`), with import from Claude Code under Settings → Skills.
- Provider-agnostic global and project memory notes under Settings → Memory carry your decisions across Claude, Codex, Antigravity, and Cursor, with manual Claude Code import and an in-chat `memory_save` tool with Undo.
- Settings → MCP now shows an effective preview per project and provider instance and lets you share an imported server across all providers in one click.
- Android adds an optional Settings toggle to keep the connection alive in the background.

## Fixes

- Mobile clients connecting through the Gustaf relay now receive the expected forwarded host and protocol headers for DPoP authentication and WebSocket upgrades.
- MCP deduplication accounts for working directory, environment variables, case-insensitive headers, and auth requirements.
- MCP servers with `disabledTools` are skipped fail-closed on providers that cannot filter individual tools instead of exposing every tool.
