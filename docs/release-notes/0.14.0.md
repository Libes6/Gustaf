## Что нового

- **Агент управляет вашим Mac.** В разрешённом треде агент видит экран, двигает мышь и печатает: откроет приложение, заполнит форму, проверит результат по снимку экрана. Работает в приложении Gustaf на macOS.
- **Управление под вашим контролем.** Функцию включает только тот, кто сидит за Mac, а разрешение даётся каждому треду отдельно кнопкой «Управление Mac» в шапке треда. Одновременно Mac управляет только один тред.
- **Остановить можно в любой момент.** Кнопкой «Стоп» в треде на компьютере, в веб-версии и на телефоне, пунктом в строке меню Mac или сочетанием ⌃⌥⌘⎋, которое работает, даже когда Gustaf не на переднем плане.
- **Понятнее запрос прав macOS.** Панель называет недостающее разрешение и открывает нужный раздел настроек; если права уже выданы, остаётся одно подтверждение.
- **Браузер агента виден в приложении** и обновляется плавнее: вкладка показывает страницу вместо заглушки.
- **Архивы команды `gustaf`** для macOS, Linux и Windows приложены к каждому релизу, команда и удалённые машины по SSH получают ту же версию, что и приложение.
- **Мелочи.** Gustaf спрашивает перед выходом, если агенты ещё работают; ссылки на другие сайты открываются в системном браузере; телефон проверяет обновления Gustaf.
