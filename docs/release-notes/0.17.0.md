## Что нового

- **Claude Code на удалённой машине.** В настройках провайдера Claude можно установить Claude Code прямо на сервер, как уже работало для Codex. Вход пока выполняется токеном `CLAUDE_CODE_OAUTH_TOKEN`.
- **Chromium во всех вкладках браузера на macOS.** Вкладки пользователя и агента рисует встроенный Chromium, указатель агента виден поверх вкладок. Браузер можно удалить и поставить заново из приложения.
- **Мобильное приложение.** Быстрая подпись на Android, плавный композер, «Отметить непрочитанным» в меню треда, 24-часовое время и корректный часовой пояс, исправления поиска файлов и фильтров.
- **Подключение телефона.** Если все сохранённые адреса компьютера локальные и ни один не отвечает, диагностика предлагает добавить маршрут через релей.
- **Antigravity.** Ход теперь надёжнее ждёт фоновые команды и субагентов и не завершается раньше времени.
- **Копирование кода из чата.** Выделенный код в строке копируется без обратных кавычек.
