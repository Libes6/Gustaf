## What’s new

- Link your own machines through the Gustaf relay, with no address or pairing code: agents on one computer can start threads on another computer signed in to the same account. The other computer asks you to approve first.
- Your phone and the desktop app list the computers in your account, so you connect with one tap and confirm the safety code on the computer.
- A computer can be set to trust devices you already approved, under Settings → Sharing & access. It is off by default, and a new device always needs your approval.
- Agents that other agents start now load about 40% fewer tool descriptions.
- Product text says Gustaf instead of the old upstream name.

## Fixes

- Codex threads started while the server is still starting no longer lose Gustaf’s tools.
- Claude threads no longer list a sign-in warning for every server that comes from a plugin.
- Settings → About shows the app’s version.
