## Что нового

- **Русский интерфейс целиком.** Переведены настройки, онбординг, браузер, панель треда, композер и мобильное приложение.
- **Свои MCP-серверы.** В настройках можно добавить MCP-серверы или импортировать их из конфигов агентов; они передаются Claude, Codex, Cursor, OpenCode и ACP-агентам.
- **Скрипты из package.json.** Меню действий проекта предлагает скрипты из `package.json` рядом со скриптами из `t3.json`.
- **Подключение телефона.** Отклонённый адрес можно добавить как маршрут, у каждого маршрута видна последняя попытка подключения.
- **Плавнее и стабильнее.** Высокие HTML-рендеры в чате больше не прыгают при прокрутке, обои работают в отдельном потоке, поток агентского браузера ограничен 30 кадрами в секунду.
- **Оболочка.** Проверка обновлений не зависает дольше 30 секунд, полноэкранный режим и внешние ссылки работают надёжнее.
