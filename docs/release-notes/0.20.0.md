## Что нового

- **Удалённый компьютер без настройки сети.** Gustaf relay теперь работает и для компьютеров: сервер без десктоп-приложения подключается командой `gustaf relay login`, а десктоп-приложение добавляет такой компьютер через «Добавить окружение» → «Gustaf relay», без открытых портов и Tailscale. Ссылку для подключения можно скопировать, а не только отсканировать.
- **Сервер на Windows запускается сам.** `gustaf up` устанавливает фоновую задачу, которая запускает сервер при входе в систему. `gustaf status` показывает её состояние, `gustaf service uninstall` убирает.
- **Подсказки при подключении.** `gustaf serve` и `gustaf pair` предупреждают, когда ссылка работает только на этом компьютере. Таймаут при добавлении окружения объясняет вероятные причины. Адрес без схемы для IP открывается по http, а на Windows `--lan` печатает команду для брандмауэра.
- **Коннекторы MCP.** В Настройки → MCP появился раздел «Коннекторы Claude Code»: видно, каким серверам нужна авторизация, и войти можно прямо из Gustaf.
- **Ходы агентов.** Force stop для Codex, тайм-ауты для зависшего Claude и ретраев провайдера, исправлены зависания при старте хода, потерянные сессии и блокировки между тредами. Длинные треды читаются быстрее.
- **Чат и композер.** Карточка вопросов агента больше не уходит под поле ввода. Исправлены поиск по треду, правка сообщений в очереди, Cmd+Enter для steer, подсказки в низком окне и десятки мелочей интерфейса.
- **Браузер.** Закрытие вкладки предпросмотра больше не вызывает диалог выхода. Мост приложения доступен только странице самого сервера, а ошибку запуска сервера можно повторить или скопировать.
