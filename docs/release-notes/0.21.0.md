## What’s new

- View a thread’s live desktop browser tabs from the mobile app. Desktop tabs open in view-only mode on your phone.
- Choose which agents receive an MCP server and turn individual tools off where supported. HTTP MCP servers support sign-in, status checks, and sign-out from Settings.
- Antigravity shows external MCP calls and refreshes its idle session when the MCP configuration changes.

## Fixes

- Desktop browser zoom now applies to CEF tabs. Closing a browser panel during tab creation no longer leaves a stray tab.
- Managed Claude installs stay selected, and subscription edits no longer recreate a deleted entry. Subscription forms reject invalid calendar dates.
