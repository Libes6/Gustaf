## Что нового

- **Живые обои чата.** Четыре сцены на выбор: Koi Pond, Jellyfish, Moonlit и Cloud Drift. Выбор доступен в настройках оформления и палитре команд.
- **Свои сцены.** Импортируйте обои в формате Claude Desktop Themes из JavaScript-файла или по ссылке на файл, в том числе из GitHub. Установленные сцены можно отключить и удалить.
- **Свой CSS в темах.** Меняйте оформление с живым предпросмотром. CSS сохраняется и экспортируется вместе с темой; поддерживаются анимации и встроенные изображения. Работает в вебе и десктопе.
- **Antigravity и фоновые задачи.** Исправлено преждевременное завершение хода, когда запущенная команда ещё работает. Длительные команды удерживают ход, а dev-серверы и другие фоновые службы могут продолжать работать после ответа.
- **Субагенты Antigravity.** Исправлено распознавание запусков и проверки состояния субагентов; прерывание потока и незавершённые вызовы теперь отображаются как ошибки вместо успешного завершения.
- **Понятнее состояние чата.** Уведомления о лимитах вынесены над полем ввода; сообщение о переносе контекста поясняет, что он произойдёт со следующим сообщением.
