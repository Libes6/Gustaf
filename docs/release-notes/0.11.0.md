## Что нового

- **Вход в аккаунт Gustaf.** Вход через GitHub на компьютере (Настройки → About → Аккаунт) и в приложении на телефоне; компьютер и телефон регистрируются как устройства аккаунта.
- **Сон компьютера.** Настройка «Не давать компьютеру засыпать» теперь работает на macOS, Windows и Linux: пока работают агенты или всегда. Её можно менять и с телефона.
- **Надёжнее запуск и выход.** Сервер всегда останавливается (на Windows вместе с процессами агентов), при неудачном запуске показывается причина, второй запуск открывает уже запущенное окно.
- **Безопаснее окно.** Команды приложения доступны только странице своего сервера, а не любому локальному сайту.
- **Сеть и телефон.** Адреса компьютера находятся на русской Windows и с Tailscale на macOS; после смены сети новый адрес добавляется маршрутом к уже сохранённому компьютеру.
- **Модели.** Список моделей обновляется при открытии выбора; у Ollama пометка «только чат»; модели, недоступные по подписке Kimi, помечаются.
- **Android.** Подписанный APK на каждом релизе, иконка без обрезки, понятный таймер «В работе · 4 с».

Plus 9 bug fixes and improvements.
